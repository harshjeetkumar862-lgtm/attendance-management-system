Why this system

Everything you need to run attendance

Built for real classrooms with multiple teachers and subjects — without unnecessary complexity.

🧑‍🏫

Separate Faculty Accounts

Every teacher gets an independent account and manages only the attendance for the subjects assigned to them.

📚

Subject-wise Attendance

One class can have many teachers. Each subject keeps its own attendance, fully isolated from the others.

🗓️

Simple Lecture Model

Create a lecture, get the student list, and mark Present or Absent. No complicated date-wise setup.

📊

Overall Percentage

Students see subject-wise and a true overall percentage calculated from total present ÷ total lectures.

📤

Excel Export

Teachers export a full class report; students download their own personal attendance report as .xlsx.

🔐

Secure & Role-Based

OTP + JWT authentication with strict access control — no teacher or student can see others' private data.
